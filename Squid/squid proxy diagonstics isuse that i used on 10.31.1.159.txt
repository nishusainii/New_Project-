The normalization logic now uses:

normalize_iptables() {
  sed -E \
    -e '/^# Generated by iptables-save /d' \
    -e '/^# Completed on /d' \
    -e 's/\[[0-9]+:[0-9]+\]/[0:0]/g'
}


This prevents harmless timestamp differences from causing a false firewall warning.

16. Added restore safety controls

The emergency recovery command does not restore immediately.

It first performs all checks. If the system matches the baseline, it stops and reports:

Decision: HEALTHY


If checks fail or differ, recovery requires two exact confirmations:

CONSOLE-READY


and:

RESTORE


This reduces the risk of an accidental restore or SSH lockout.

The script also does not automatically apply Netplan. After restoration, Netplan must be tested manually from protected console access:

sudo netplan --debug generate
sudo netplan try --timeout 120
