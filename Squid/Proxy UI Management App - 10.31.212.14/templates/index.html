FORWARD CHAIN Proxy Client Forwarding

Permit internal source client IPs to access cloud destination IPs on ports 80 (HTTP) & 443 (HTTPS).

ip saddr { client_ips } ip daddr { dst_ips } tcp dport { 80, 443 } accept
POSTROUTING NAT NAT Masquerade on Egress

Masquerade outbound client requests exiting physical interface (e.g. ens18) to external destinations.

oifname "ens18" ip saddr { client_ips } ip daddr { dst_ips } tcp dport { 80, 443 } masquerade
INPUT CHAIN Allow Squid Proxy Port

Allow inbound connections to Squid Proxy port (e.g. 8085) or Management Web Portal (port 5000).

tcp dport 8085 accept comment "Squid Proxy Port 8085"
INPUT & FORWARD Drop / Block Malicious IP

Immediately drop all inbound and forwarding packets originating from a hostile IP or subnet.

ip saddr 1.2.3.4 drop comment "Blocked IP"
