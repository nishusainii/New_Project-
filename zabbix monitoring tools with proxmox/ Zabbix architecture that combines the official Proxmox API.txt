For your environment (Proxmox cluster + Linux servers + Squid proxy + multi-WAN network), I would recommend a layered Zabbix architecture that combines the official Proxmox API integration with Zabbix agents on critical hosts. The official Zabbix Proxmox integration supports monitoring Proxmox VE through the API, including nodes, VMs, containers, storage, and cluster resources.

Layer 2: Proxmox Monitoring

The official "Proxmox VE by HTTP" template works through the Proxmox API and discovers:

Cluster resources
Nodes
VM instances
LXC containers
Storage resources
Network interfaces

It requires a Proxmox API token and appropriate read permissions.

Create Monitoring User
zabbix-monitor@pve
Role: PVEAuditor

Create API Token
zabbix-monitor@pve!zabbix


Configure the token in Zabbix host macros as described by the official integration.

       +--> Zabbix Agent Monitoring

       |

This gives you a single pane of glass for Proxmox, storage, networking, Squid, VPN services, and WAN health while preserving detailed historical performance data. The official Proxmox HTTP template provides automatic discovery of cluster components, VMs, containers, and storage resources through the Proxmox API.
