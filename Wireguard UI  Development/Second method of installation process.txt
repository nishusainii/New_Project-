Here is the step-by-step guide to installing and configuring a WireGuard VPN Server and connecting Clients (Linux, Windows/macOS, and Mobile).
  ──────
  ### Prerequisites & Example Network Layout

  • Server Public IP: 203.0.113.10 (replace with your server's actual public IP)
  • VPN Subnet: 10.0.0.0/24
  • Server VPN IP: 10.0.0.1
  • Client VPN IP: 10.0.0.2
  • Listening Port: 51820 (UDP)
  ──────
  ## Part 1: WireGuard Server Setup (Ubuntu / Debian)

  ### 1. Install WireGuard

  Update your package manager and install WireGuard and iptables tools:

    sudo apt update && sudo apt install -y wireguard iptables qrencode
  ──────
  ### 2. Enable IP Packet Forwarding

  Allow the Linux kernel to route traffic through the VPN tunnel.

  1. Open /etc/sysctl.conf:
    sudo nano /etc/sysctl.conf

  2. Uncomment or add the following lines:
    net.ipv4.ip_forward=1
    net.ipv6.conf.all.forwarding=1

  3. Apply the changes immediately:
    sudo sysctl -p

  ──────
  ### 3. Generate Server Keys

  Keys are stored in /etc/wireguard/ with restricted permissions:

    cd /etc/wireguard
    umask 077
    wg genkey | tee server_private.key | wg pubkey > server_public.key

  View the generated keys:

    cat server_private.key
    cat server_public.key
  ──────
  ### 4. Determine Default Network Interface

  Find the name of your server's public network interface (usually eth0, ens3, or enp1s0):

    ip route show default | awk '{print $5}'

  (Assume the output is eth0 for the steps below).
  ──────
  ### 5. Create the Server Configuration File

  Create /etc/wireguard/wg0.conf:

    sudo nano /etc/wireguard/wg0.conf

  Paste the following configuration (replace <SERVER_PRIVATE_KEY> and eth0 if your interface differs):

    [Interface]
    Address = 10.0.0.1/24
    ListenPort = 51820
    PrivateKey = <PASTE_CONTENTS_OF_server_private.key>
    SaveConfig = false
    
    # NAT routing rules for forwarding client traffic to the internet
    PostUp = iptables -A FORWARD -i wg0 -j ACCEPT; iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
    PostDown = iptables -D FORWARD -i wg0 -j ACCEPT; iptables -t nat -D POSTROUTING -o eth0 -j MASQUERADE

  Set appropriate file permissions:

    sudo chmod 600 /etc/wireguard/wg0.conf
  ──────
  ### 6. Configure Firewall

  If you are using ufw:

    sudo ufw allow 51820/udp
    sudo ufw allow OpenSSH
    sudo ufw enable
  ──────
  ### 7. Start and Enable WireGuard Server

    sudo systemctl enable --now wg-quick@wg0

  Check the status:

    sudo wg show
  ──────
  ## Part 2: Client Setup & Pairing

  ### 1. Generate Client Keys

  On the server (or locally on your client machine), generate the client's key pair:

    cd /etc/wireguard
    wg genkey | tee client_private.key | wg pubkey > client_public.key
  ──────
  ### 2. Register the Client Peer on the Server

  Add the client to /etc/wireguard/wg0.conf:

    sudo nano /etc/wireguard/wg0.conf

  Append the [Peer] block at the bottom:

    [Peer]
    PublicKey = <PASTE_CONTENTS_OF_client_public.key>
    AllowedIPs = 10.0.0.2/32

  Reload the server configuration without dropping existing connections:

    sudo wg syncconf wg0 <(wg-quick strip wg0)
  ──────
  ### 3. Create the Client Profile (client.conf)

  Create a client.conf file containing:

    [Interface]
    PrivateKey = <PASTE_CONTENTS_OF_client_private.key>
    Address = 10.0.0.2/24
    DNS = 1.1.1.1, 8.8.8.8
    
    [Peer]
    PublicKey = <PASTE_CONTENTS_OF_server_public.key>
    Endpoint = 203.0.113.10:51820
    AllowedIPs = 0.0.0.0/0, ::/0
    PersistentKeepalive = 25

  │ Note on AllowedIPs:
  │
  │ • 0.0.0.0/0, ::/0 routes all traffic (Full Tunnel) through the VPN.
  │ • If you only want access to the VPN internal network (Split Tunnel), use 10.0.0.0/24.
  ──────
  ## Part 3: Connecting from Clients

  ### A. Mobile Devices (iOS / Android)

  1. Generate a terminal QR code on the server:
    qrencode -t ansiutf8 < /etc/wireguard/client.conf

  2. Open the official WireGuard app on your phone.
  3. Tap + > Scan QR Code, give it a name, and toggle the connection on.
  ──────
  ### B. Windows / macOS

  1. Download the installer from the official WireGuard website https://www.wireguard.com/install/.
  2. Securely copy client.conf to your machine.
  3. Open WireGuard > Add Tunnel > select client.conf.
  4. Click Activate.
  ──────
  ### C. Linux Client

  1. Install WireGuard:
    sudo apt update && sudo apt install -y wireguard

  2. Move client.conf to /etc/wireguard/wg0.conf:
    sudo cp client.conf /etc/wireguard/wg0.conf
    sudo chmod 600 /etc/wireguard/wg0.conf

  3. Start the tunnel:
    sudo wg-quick up wg0
  (To disconnect: sudo wg-quick down wg0)
  4. To enable on boot:
    sudo systemctl enable wg-quick@wg0

  ──────
  ## Part 4: Verification

  1. On the Server:
    sudo wg show
  You should see the peer listed with an active handshake and data transfer counters:
    peer: <CLIENT_PUBLIC_KEY>
      endpoint: <CLIENT_IP>:<PORT>
      latest handshake: 12 seconds ago
      transfer: 1.24 KiB received, 892 B sent

  2. On the Client:
  Test your external IP to confirm your traffic is routed through the server:
    curl https://ifconfig.me
  The returned IP should match your server's public IP (203.0.113.10).
