Client Connection Guide

Everything needed to connect remote machines to this SSL VPN

1. Mock TUN Mode (No Root / Safe Testing)

No Sudo Required

Simulates a complete VPN tunnel inside memory. Verifies the TLS 1.3 handshake, credentials, routing tables, and keepalives without modifying host networking interfaces.

cd testing
python3 vpn_client.py --server 127.0.0.1 --port 443 --username admin --mock-tun

2. Real Kernel TUN Mode (Full OS Routing)

Requires Sudo

Creates a real kernel network interface (e.g. ssladmin) so system packets and applications route through the VPN tunnel gateway.

cd testing
sudo python3 vpn_client.py --server 127.0.0.1 --port 443 --username admin

Once connected, verify with: ip addr show ssladmin

3. Standalone Client via Docker

Zero Host Dependencies

Runs the standard Python client inside the official container image.

docker run --rm -it --network host --entrypoint python3 innspark/sslvpn:1.0.0 \
    vpn_client.py --server 127.0.0.1 --port 443 --username admin --mock-tun
