4. Architectural Performance Observations

  • ZFS Storage Pool (Local RAIDZ2): Delivers extreme direct I/O write throughput (up to 6.25 GB/s burst / 100K+ 4K IOPS) due to direct memory/ZIL transaction striping across the 7 SAS disks.
  • Ceph Distributed Storage (RBD 3x Replication): Delivers steady enterprise throughput (120 MB/s – 250 MB/s write / 1,000+ 4K IOPS), guaranteeing that every byte is fully written and acknowledged on 3 separate physical nodes across the 10G interconnect before returning success.
