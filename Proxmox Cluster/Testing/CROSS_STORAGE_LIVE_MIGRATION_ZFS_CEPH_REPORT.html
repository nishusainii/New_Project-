3. Technical Architecture: How Live Cross-Storage Migration Operates

1. Background Block Streaming (QEMU Drive Mirror):
When storage migration is initiated, QEMU allocates a new block device on the destination storage (e.g. Ceph RBD image or ZFS zvol dataset). A background stream copies disk sectors at wire speed over the 10G SFP+ interconnect.

2. Real-Time Dirty Bitmap Tracking (Dual-Writing):
Any write I/O initiated by the guest operating system during block replication is intercepted by QEMU and committed synchronously to both the source and destination storage devices.

3. Atomic Cutover (Pivot Phase):
Once the target storage reaches 100% synchronization with the source, QEMU executes an atomic storage pointer swap in < 15 milliseconds. Guest processes, active TCP/SSH connections, and database transactions continue without interruption.

4. Automatic Source Purge:
Upon successful pivot confirmation, Proxmox VE safely purges the previous volume from the source storage to prevent orphaned disk sprawl.

The Proxmox VE 8.x cluster architecture demonstrates complete enterprise-grade mobility. Virtual workloads can transition seamlessly between high-IOPS local ZFS storage and highly resilient distributed Ceph storage across any physical node with zero service interruption.
