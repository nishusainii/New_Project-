7. Technical Root Cause Analysis (RCA) Summary

  • Drive Hot-Pull SCSI Desync: Hot-swapping physical SAS drives caused Linux SCSI mid-layer re-enumeration (/dev/sdb [8:16] ➡️ /dev/sdn [8:208]), leaving LVM device-mapper pointing to stale minor handles. Formulated standard automated SOP (vgchange -an, udevadm trigger, vgchange -ay, ceph-volume lvm activate --all) to instantly restore OSDs without rebooting.
  • Web UI Transition Artifacts: Resolved HA maintenance mode wrench and ? icons by restoring pvestatd metric broadcast daemons across nodes.
