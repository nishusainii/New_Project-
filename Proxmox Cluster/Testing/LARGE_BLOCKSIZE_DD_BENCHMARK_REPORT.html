1. Executive Summary & Test Parameters

This benchmark measures direct synchronous single-block transfer throughput where the dd block size parameter (bs) is explicitly set to multi-megabyte payloads (bs=10M, bs=20M, bs=50M, bs=100M, bs=200M, bs=500M, and bs=1000M with count=1 and oflag=direct, conv=fdatasync) to evaluate large-payload I/O streaming efficiency.

3. Key Engineering Findings

  • Ceph Throughput Scaling with Block Size: When switching from small 1MB/4KB blocks to large 50M–1000M blocks, Ceph distributed throughput scales from ~68 MB/s up to 280+ MB/s write and 838+ MB/s read, demonstrating high pipeline efficiency for large media/backup transfers.
  • ZFS Large Block Acceleration: ZFS RAIDZ2 sustains 1.5 GB/s to 3.8+ GB/s across all multi-megabyte block sizes due to in-memory transaction coalescing across the local SAS HBA controller.
