You can give **physical tags/labels to each front disk bay** after blinking the locate LED. Use a printed adhesive label with the node, storage type, OSD or ZFS position, and slot number.

## Recommended tag format

<Node>-<Storage>-<ID>-S<Slot>

Examples:

PX22-CEPH-OSD0-S0  

PX22-ZFS-R2-01-S4  

PX22-SPARE-S11

## Safe tagging process

Perform one server and one disk at a time.

### 1. Start the locate LED

Example for `prox22`, slot 4:

ssh root@prox22  

  

PERC=/usr/local/sbin/perccli64  

"$PERC" /c0/e252/s4 start locate

### 2. Verify the physical bay

Confirm that only the expected front bay is blinking.

For this example:

Server : prox22  

Bay : Slot 4  

Disk : /dev/sde  

Serial : ZYDG62WJ  

Role : ZFS RAIDZ2

### 3. Attach the printed label

Attach:

PX22-ZFS-R2-01-S4

Prefer attaching the label to the drive carrier handle without covering:

- Activity LED
- Fault LED
- Locate LED
- Release latch
- Ventilation opening
- Existing Dell serial label

### 4. Stop the locate LED

"$PERC" /c0/e252/s4 stop locate

### 5. Continue with the next slot

"$PERC" /c0/e252/s5 start locate

After labeling:

"$PERC" /c0/e252/s5 stop locate

## Interactive labeling loop

Run locally on each node. This blinks only one disk at a time:

PERC=/usr/local/sbin/perccli64  

  

for slot in {0..11}; do  

echo  

echo "=========================================="  

echo "Locating $(hostname) enclosure 252 slot $slot"  

echo "=========================================="  

  

"$PERC" /c0/e252/s"$slot" start locate  

  

read -r -p "Apply the correct label, then press Enter: "  

  

"$PERC" /c0/e252/s"$slot" stop locate  

done  

Do not exit the script while an LED is blinking. If you interrupt it, stop the current locate LED manually:

PERC=/usr/local/sbin/perccli64  

"$PERC" /c0/e252/s4 stop locate

Replace `s4` with the slot that was blinking.

## Recommended label contents for maintenance

If you have enough label space, use two lines:

PX22-ZFS-R2-01-S4  

SN: ZYDG62WJ

For Ceph:

PX22-CEPH-OSD0-S0  

SN: ZYDGFEW6

For the reserved disk:

PX22-SPARE-S11  

SN: ZYDFW4AP

The serial number is important because `/dev/sda`, `/dev/sde`, and similar Linux names can change after reboot. The permanent physical identification should use:

Host + PERC slot + serial number + storage role

## Color-tag recommendation

For quicker physical identification:

Blue label : Ceph OSD  

Green label : ZFS RAIDZ2  

Yellow label : Reserved/spare  

Red label : Failed or do-not-use disk

Do not mark the reserved slot as a ZFS hot spare unless you actually add `/dev/sdl` to the pool with `zpool add ... spare`. Currently, label it only as **RESERVED**, not as an active spare.
