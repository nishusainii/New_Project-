📌 Executive Summary & Scope of Validation

An end-to-end, disruptive fault injection test suite was executed against the 3-node enterprise production cluster cisai-pve to empirically evaluate cluster resilience under catastrophic infrastructure failures. Testing evaluated: (1) Dual-node simultaneous hardware power loss to verify Corosync quorum enforcement and split-brain prevention; (2) Single-node network isolation to measure Linux hardware watchdog fencing, HA manager CRM orchestration, and VM relocation timings; and (3) Total Ceph storage fabric failure (nic3 link loss on all nodes) to benchmark client I/O suspension safety and exact post-restoration storage convergence time.

Key Finding: Zero Split-Brain & Flawless Storage Recovery
Under dual-node shutdown, Proxmox VE correctly protected shared block integrity by pausing VM workloads upon losing quorum (1/3 votes), eliminating split-brain corruption. Upon single node isolation, hardware watchdog fenced the isolated host in 53s, completing VM failover in 2m 26s. Following total Ceph link failure, the storage engine resumed all 12 OSDs in 21s and returned to clean HEALTH_OK within 28 seconds.

🛡️ Quorum Mechanics & Split-Brain Prevention

In a 3-node Proxmox cluster, quorum requires strictly > total_votes / 2 (minimum 2 votes). When both prox23 and prox24 powered off, the surviving node prox22 held only 1 vote (33.3%).

Engineered Safety Response: Proxmox VE immediately transitioned the cluster filesystem (pmxcfs) to read-only mode and the HA Cluster Resource Manager halted VM execution. This design guarantees that if the two "dead" nodes were actually running in an isolated network, they could not write to shared Ceph storage simultaneously, eliminating 100% of potential data corruption.

🔄 Cold Boot Auto-Recovery Evaluation

Upon power restoration, node prox24 initialized in 44 seconds. The moment prox24 communicated over vmbr0 with prox22, Corosync achieved 2/3 votes.

Automated Service Recovery: Without requiring any manual sysadmin intervention:

  • pmxcfs restored read-write quorum within 500ms.
  • HA Manager evaluated resource status and launched all production VMs at T+161s.
  • Ceph PG recovery engine background-scrubbed all delta writes, returning to HEALTH_OK at T+305s.

⚡ Watchdog Fencing & Failover Architecture

High-availability failover requires absolute certainty that a disconnected node is not still writing to shared storage. Proxmox VE achieves this via Self-Fencing Linux Watchdog.

When prox24 was isolated, it stopped receiving Corosync tokens. Because it could not see a majority quorum, its local HA Local Resource Manager (pve-ha-lrm) refused to pet the hardware watchdog. At exactly T+53s, the watchdog triggered a hard hardware reset, guaranteeing prox24 was completely dead before surviving nodes took ownership of its disk images.

🔍 Storage Network Isolation Architecture

A critical design feature validated by this test is Physical Network Segregation between management/corosync (vmbr0) and storage (nic3).

When nic3 went down, the nodes never mistook the storage outage for a host death because Corosync heartbeats continued unimpeded over vmbr0. Consequently, HA watchdog fencing was not erroneously tripped, avoiding unnecessary and dangerous cascading reboots across the datacenter.

🔧 Enterprise Hardening Recommendations
1. Corosync Redundant Ring (Dual Link)
Configure a secondary Corosync ring over a distinct physical NIC (ring1_addr). This ensures a single cable pull on vmbr0 will not trigger node fencing if the secondary ring remains intact.
2. Chrony NTP Rapid Step on Boot
Add makestep 1 3 to /etc/chrony/chrony.conf on all nodes to prevent transient Ceph monitor clock skew warnings following cold reboots.
3. Ceph Public vs Cluster Mesh Split
Split Ceph traffic: client VM access on public_network and back-end replication on a dedicated cluster_network to prevent I/O latency spikes during heavy rebuilds.
4. Automated HA VM Rebalancing
Establish an automated post-recovery hook or Ansible playbook to balance VMs back to their preferred nodes once isolated hosts rejoin and stabilize.
