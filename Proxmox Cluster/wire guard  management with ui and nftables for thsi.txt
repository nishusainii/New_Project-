  ### How to Deploy on a New Server in the Future
  1. Copy the zip file to your target server:
    scp wireguard-enterprise-production.zip user@<new-server-ip>:/tmp/
  2. Extract on the target server:
    sudo mkdir -p /opt/wireguard-enterprise
    sudo unzip /tmp/wireguard-enterprise-production.zip -d /opt/wireguard-enterprise
    cd /opt/wireguard-enterprise

  3. Configure environment (IP, ports, admin password):
    sudo nano .env

  4. Run the automated offline installer:
    sudo bash scripts/deploy-offline.sh
  Or with Docker Compose:
    docker load < wireguard-enterprise-image.tar.gz
    sudo docker compose up -d
