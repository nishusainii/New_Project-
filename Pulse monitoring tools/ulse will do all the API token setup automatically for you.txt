That message means Pulse will do all the API token setup automatically for you, so you don't have to create the user or token manually.

Here's what each step means:

1. Creates monitoring user pulse-monitor@pbs

Pulse will create a dedicated account on your Proxmox Backup Server (PBS):

pulse-monitor@pbs


This is a service account used only for monitoring. It is separate from your root@pam account.

2. Generates secure API token

Pulse creates an API token for that monitoring user, for example:

User: pulse-monitor@pbs
Token: pulse


Internally it becomes something similar to:

pulse-monitor@pbs!pulse


along with a secret token.

You don't need to manually copy or store the token because the setup script handles it.

3. Sets up Audit permissions (read-only)

Pulse assigns a read-only role.

This means Pulse can:

✅ View backup jobs
 ✅ View datastore status
 ✅ View storage usage
 ✅ View node health
 ✅ View system statistics

But it cannot:

❌ Delete backups
 ❌ Modify datastores
 ❌ Change PBS configuration
 ❌ Create or remove users

This follows the least-privilege security model.

4. Automatically registers server with Pulse

Normally you would:

Create user
Create token
Copy token ID
Copy token secret
Paste them into Pulse

With the generated setup command, the script does all of that automatically.

Example workflow:

Pulse Dashboard
        │
Generate Setup Command
        │
        ▼
Run on PBS Server
        │
        ▼
Create User
        ▼
Create API Token
        ▼
Assign Read-Only Permissions
        ▼
Send Token to Pulse
        ▼
PBS appears automatically in Pulse

What happens when you run the command?

If Pulse generates a command like:

curl ... | bash


and you run it on the PBS host as root, the script typically:

Creates the monitoring account.
Creates the API token.
Applies audit permissions.
Sends the token information securely back to your Pulse server.
Registers the PBS node.

After it finishes, the PBS server should appear in the Pulse dashboard without any manual token entry.

Is it safe?

Generally yes, provided:

The command is generated by your own Pulse instance.
You review the command before running it.
You understand that it will create a service account and API token automatically.

As a best practice, before running any:

curl ... | bash


command, you can inspect it first:

curl -fsSL "URL"


or

curl -fsSL "URL" -o pulse-setup.sh
less pulse-setup.sh


Then run it after reviewing:

bash pulse-setup.sh


This lets you verify exactly what changes will be made on the Proxmox/PBS server.
