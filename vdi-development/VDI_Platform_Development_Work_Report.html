1. Executive Summary

This work report presents an executive and technical summary of all milestones accomplished to date for the Enterprise Virtual Desktop Infrastructure (VDI) Platform.

The objective of this project was to architect, automate, harden, and document a complete, on-premises, clientless virtual desktop ecosystem capable of delivering both Ubuntu 24.04 LTS Linux and Windows 10/11 Enterprise desktop workloads directly inside modern web browsers.

All hypervisor automation, golden image provisioning routines, Sysprep and cloud-init sealing scripts, clientless gateway services, Active Directory integration, and multi-factor authentication systems have been engineered, tested, and validated for production deployment.

2. Completed Milestones & Deliverables

Milestone 1: Ubuntu 24.04 LTS VDI Golden Image & Automation

Engineered a lightweight, high-density Linux VDI template based on Ubuntu Server 24.04 LTS (Noble Numbat):

  • Desktop Environment: Configured lightweight XFCE4 desktop session, achieving an ultra-low idle memory footprint of ~350 MB RAM (vs 1.8 GB+ for GNOME).
  • Display Transport: Deployed xrdp and xorgxrdp for low-latency RDP streaming with pulseaudio-module-xrdp audio redirection.
  • Hypervisor Integration: VirtIO SCSI Single controller with iothread=1 and discard=on (TRIM), coupled with QEMU Guest Agent.
  • Automated Scripts: Created create-ubuntu-vdi-build-vm.sh, seal-ubuntu-vdi.sh, and verify-clone-uniqueness.sh.
  • Documentation: Complete Markdown runbook (1,160+ lines), formatted HTML guide, and printable PDF.

Milestone 2: Windows 10 / 11 Enterprise VDI Golden Image & Sysprep

Engineered a standardized, high-performance Windows VDI golden image optimized for Proxmox VE:

  • Virtual Hardware: Modern q35 PCIe architecture, OVMF UEFI, vTPM 2.0 (Windows 11 compatibility), and VirtIO SCSI.
  • Driver Integration: Embedded Fedora VirtIO driver suite (vioscsi, NetKVM, ballooning, serial console).
  • PowerShell Optimization: Built optimize-and-seal-windows-vdi.ps1 to debloat consumer UWP packages, disable telemetry, optimize visual effects, and prioritize WDDM graphics drivers for 60 FPS RDP performance.
  • Sysprep Automation: Engineered unattend.xml to automate OOBE and bypass local account creation, alongside verify-windows-clone-uniqueness.sh to confirm unique SIDs.
  • Documentation: Master Windows runbook, formatted HTML guide, and printable PDF.

Milestone 3: VDI Technology Assessment & Comparative Analysis

Conducted an in-depth architectural comparison between open-source VDI platforms:

  • abcdesktop.io Evaluation: Analyzed its Kubernetes container desktop streaming model. Identified that while excellent for Linux application isolation, it cannot connect to or manage full Proxmox QEMU virtual machines.
  • Apache Guacamole vs. abcdesktop: Formulated the architectural decision matrix establishing Guacamole as the necessary choice for full Windows 10/11 and Ubuntu OS virtual machines.
  • rustguac Evaluation: Investigated rustguac as a lightweight, high-performance Rust alternative with built-in Docker VDI and H.264 WebCodecs.

Milestone 4: Apache Guacamole Production Gateway Implementation

Designed and delivered a production-ready, clientless remote desktop gateway stack:

  • Container Stack: Decoupled Docker Compose architecture featuring guacd:1.5.5, guacamole:1.5.5, postgres:16-alpine, and nginx:1.27-alpine.
  • Active Directory SSO: Chained LDAP authentication with Bitwise search filtering to immediately deny access to deactivated AD accounts.
  • Two-Factor Authentication: Integrated TOTP MFA (RFC 6238) with QR code enrollment and administrative reset procedures.
  • Hardened Nginx Reverse Proxy: Enforced TLS 1.2/1.3, HSTS, and low-latency HTTP/1.1 WebSocket upgrades.
  • Connection Profiles: Configured SSO pass-through tokens (${GUAC_USERNAME}), Windows NLA, and dynamic Ubuntu desktop resizing via the Display Update virtual channel.
  • Auditing & Backups: Configured protocol-level session video recording (guacenc) and automated nightly database backups.
